Before we start

Two things to check.

On a Mac?

You're ready. Nothing to do. We'll open Terminal in a moment.

On Windows?

You need WSL first, and it needs a restart. Open PowerShell as administrator, run wsl --install, restart, then open Ubuntu from the Start menu and follow along there.

You do not need to know git, the terminal, or what an environment variable is. You will not be asked to copy a single password.

Step 1 of 5

Paste one line.

On a Mac press ⌘ Space, type Terminal, hit enter. Then paste this:

curl -fsSL https://insurwreck-desk.preview.plumhq.com/go | bash

It installs, checking each one first

  • A proper terminal (Ghostty)
  • Claude Code — the agent you'll build with
  • Node and the Salesforce CLI
  • The Insurwreck toolkit
  • A project folder at ~/insurwreck

Three to five minutes. A tick appears per step. If it asks for your Mac password, that's the installer needing permission — type it and carry on. Safe to run twice; it skips what's done.

Step 2 of 5

The installer ends by printing a line to paste, finishing in claude --permission-mode auto. Paste that. When the agent starts, type:

No idea yet? Say "still exploring" — it's a valid answer and we'll help you pick one later.

Step 4 of 5 · The one everybody skips

Quit it.
Start it again.

Close the window. Reopen your terminal. Paste the same launch line the installer gave you.

This restart is what switches the Plum data on. Skip it and the data server will look broken — and you'll spend twenty minutes debugging something that isn't wrong.

Why: the data connections read your tokens when the agent starts, and your tokens only existed a minute ago.

Step 5 of 5

Prove it works.

Type this. It checks your whole setup and explains anything wrong in plain English.

iw-doctor

All green?

You're done. Sit tight while we get everyone else there.

Something red?

Read what it says — it usually tells you the fix. "Restart" genuinely means restart. If it says a token was rejected, raise your hand; re-running won't help.

The safety nets

Three things
you don't have to think about.

Undo you never asked for

Every file change is quietly checkpointed. Say "go back to before that change" and it will.

Secrets stay out of code

Paste a real key into a file and it stops you, explains why, and puts it somewhere safe instead.

No catastrophic commands

Anything that would wipe your folder or throw away work asks what you actually meant.

None of this blocks you. It's there so one wrong keystroke doesn't end your day.

Your data

Real Plum data.
Handled carefully.

What you get

Ten read-only slices: claims, covered lives, support tickets, NPS, policy schedules and more. Ask for what you want — you don't need table names.

De-identified: no member names, ages banded, free-text notes stripped.

Read this once

It is still confidential company data. Never screenshot it into Slack. Never put a raw row on a slide.

Aggregates and charts in your demo are fine. Raw records are not.
